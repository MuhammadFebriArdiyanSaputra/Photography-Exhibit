# Photography Exhibit

A minimalist photography gallery layout built with **Tailwind CSS** as part of the **freeCodeCamp** curriculum. This lab focuses on structuring responsive grid layouts, styling cards with utility classes, and presenting visual content cleanly.

## Features

- **CSS Grid Layout:** Uses Tailwind's `grid`, `grid-cols-*`, and `gap-*` utilities to arrange exhibition cards evenly.
- **Styled Exhibit Cards:** Features dark-themed cards with rounded borders (`rounded-2xl`), consistent padding (`p-5`), and structured typography (`.subheading` and `.description`).
- **Curated Visuals:** Showcases architectural, alpine, and coastal photography with descriptive alt text.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` directly in your browser to view the exhibit.
